# 音频说明

当前目录存放 12 段**生成音频**（机器合成，非真人录音、非田野采集），前端优先播放；正式提交前请用两岸田野采集的真人录音覆盖同名文件。

推荐格式：`.mp3` 或 `.m4a`，单词 + 一句生活短句，保留适度环境音，48kHz / 24bit 源文件。

## 音频清单

首版 3 组、每组两岸各 2 位讲述者。**默认播放**与**换声音后播放**是两段不同音频：

| 词条 | 讲述者 | 大陆音频（普通话） | 台湾音频（台湾口音） |
| --- | --- | --- | --- |
| 太阳 / 日頭 | voice 1（默认） | `taiyang-cn.mp3` | `taiyang-tw.mp3` |
| 太阳 / 日頭 | voice 2（换声音） | `taiyang-cn-alt.mp3` | `taiyang-tw-alt.mp3` |
| 期 qī / 期 qí | voice 1（默认） | `qi-cn.mp3` | `qi-tw.mp3` |
| 期 qī / 期 qí | voice 2（换声音） | `qi-cn-alt.mp3` | `qi-tw-alt.mp3` |
| 微 wēi / 微 wéi | voice 1（默认） | `wei-cn.mp3` | `wei-tw.mp3` |
| 微 wēi / 微 wéi | voice 2（换声音） | `wei-cn-alt.mp3` | `wei-tw-alt.mp3` |

音频路径已在 `../js/data.js` 的 voice `audio` 字段逐个填写。点进来先播放 `voices[0]` 的音频，点「换声音」后播放 `voices[1]` 的音频（`-alt` 文件）。

## 回退机制

音频加载失败时，页面回退到浏览器语音合成，并在体验顶部、词卡角标与「关于」中标注。生成音频为真人口播的替代样带，界面已标注“生成音频 · 非田野采集”，不会冒充真人采访。
