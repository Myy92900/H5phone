# 同源共响 · 互动 H5

一个 30 秒的两岸同源词汇声音体验：**点词卡 → 听发音与故事 → 看字形溯源 → 多声轮播 → 生成同源卡**。

## 快速打开

- 直接双击 `index.html` 即可体验大部分功能。
- 推荐在本地起一个静态服务器，分享 API、剪贴板和音频路径会更稳定：

```bash
cd 同源共响_H5
python -m http.server 8080
# 打开 http://localhost:8080
```

## 已实现

- 首版 3 组同源词：1 组同源异形词（太阳 / 日头）+ 2 组同源异读词（期 / 微）；完整词库 20 组另含语义偏移类。
- 每组词两岸各 2 个声音，共 12 个声音档案；均为团队撰写的演示文本，非田野采集，正式版替换为受访者确认稿。支持单侧换声音、跨岸对听、四声自动轮播。
- 声音层：已接入 6 段生成音频（普通话 / 台湾口音各 3 段），同岸两位讲述者共用该段音轨；音频加载失败时回退到浏览器语音合成。生成音频为机器合成，非真人录音。
- 声调层：拼音显示调号与调值，词卡绘制四声轮廓，词源详情附台湾注音；点「声调 / 声调示范」可用 Web Audio 听四声滑音，第二声以金色强调。
- 口音层：台湾侧单字示范读本地标准音（期 qí / 微 wéi）；回退到浏览器合成声时用同音字（其 / 围）引导读音。
- 交互层：不再使用灰色禁用按钮，改为点词卡后浮现「听另一岸」、两岸都听后浮现「看词源」，并附“下一步会出现在这里”的提示。
- 中央词源舞台：双字向中心汇流、共同源字落印、声波涟漪、轻量共鸣音与移动端震动。
- “听见—溯源—共鸣”三段进度由交互步骤驱动（0 / 45 / 100），无倒计时压迫；30″ 仅作建议时长提示。
- 完整词源弹层：共同源头、分流路径、4 段演示故事、考据文献。
- 本地生成 1080×1440 同源卡，可保存图片、系统分享或复制带词条锚点的链接。
- 响应式：桌面三栏、移动端双卡 + 中央舞台 + 声音 dock。
- 无障碍：键盘操作、焦点陷阱、字幕文本、`prefers-reduced-motion` 降级。

## 接入真人录音（重要）

当前已随项目提供 6 段**生成音频**（普通话 / 台湾口音各 3 段，机器合成、非真人录音、非田野采集），前端优先播放；生成音频不是田野采集，页面已明确标注，不会冒充真人采访。正式提交前，请把两岸田野采集的真人录音放入 `assets/audio/`，覆盖同名文件，或在 `assets/js/data.js` 中为每个 voice 修改 `audio` 字段：

```js
{
  tag: "青年 · 在校学生",
  place: "福建 · 厦门",
  quote: "……",
  story: "……",
  audio: "assets/audio/taiyang-cn.mp3",
  ttsText: "太阳"
}
```

当前音频清单（每组两岸各一段，同岸两位讲述者共用）：

| 词条 | 大陆音频 | 台湾音频 |
| --- | --- | --- |
| 太阳 / 日頭 | `taiyang-cn.mp3` | `taiyang-tw.mp3` |
| 期 qī / 期 qí | `qi-cn.mp3` | `qi-tw.mp3` |
| 微 wēi / 微 wéi | `wei-cn.mp3` | `wei-tw.mp3` |

录音建议：单词 + 一句生活短句，保留适度环境音，48kHz/24bit，轻度降噪。音频存在时自动优先播放；加载失败才回退浏览器合成声，并保留注音、声调轮廓与四声示范作为辅助。

## 内容说明

- 所有故事为团队撰写的演示文本，非田野采集；正式版替换为受访者本人确认并签署授权的稿件。
- 词源说明依据项目提案与所列文献整理；正式上线前建议由汉语音韵学、两岸词汇研究方向专家复审。
- 同源异读词（期 / 微）为同字异读，两岸写法相同、读音不同；台湾侧附注音与声调示范，以真人录音 / 注音为准。
- “日头”为台湾国语口语高频词，带闽南语底色但非纯闽南语词；详情页已保留该注释。
- 分享卡只在本机 Canvas 生成，不上传任何内容；“乡音共建”为演示入口，不收集个人信息。
